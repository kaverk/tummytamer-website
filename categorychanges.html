eBay Category Changes - Oct 2021

October 13, 2021

What's This About?

eBay has updated some of their categories for listings. Any SeeSpotBid Search Alerts referencing these old category IDs may not return the results you want (eBay returns results from a "similar" parent category, which usually means more results than before).

What You Need To Do

To update the category for affected Search Alerts, go into the Edit menu for that Search Alert and select a new category, then click "Save." There's no easy way to know which Search Alerts are affected without going into the Edit menu; if you click "Category" and it goes to the "All Categories" level (Antiques, Art, Baby, etc.), then that means the Search Alert was using a deleted category. If you click "Category" and it goes to the same one it did before (as expected), it means that Search Alert is fine and doesn't need to be changed.
